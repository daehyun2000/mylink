# 마이링크 (MyLink)

「아이디어를 현실로: 바이브 코딩」 과제용 마이링크 프로젝트입니다.
여러 링크를 한 페이지에 모아 공유하는 링크 모음 페이지입니다.

## 기능
- 링크 목록 보기 (Read)
- 링크 추가 (Create) — 빈 칸, 주소 형식 검증
- 링크 수정 / 삭제 (Update / Delete)
- 링크별 클릭 수 표시
- 브라우저 저장소(localStorage)에 저장되어 새로고침해도 유지
- 모바일 화면 대응, 다크 모드 지원

## 사용 방법
1. 페이지 하단의 **✏️ 편집** 버튼을 누릅니다.
2. 아이콘, 제목, 주소를 입력하고 **추가**를 누릅니다.
3. 링크 옆 ✏️ / 🗑️ 버튼으로 수정·삭제합니다.

## 배포
GitHub Pages로 배포했습니다. 저장소의 `index.html`이 그대로 사이트가 됩니다.
